# Task Management — PostgreSQL

## 1. Что это за проект?

Учебный проект на Python и PostgreSQL — простая база данных для управления задачами.

Я создал базу, состоящую из трёх таблиц, заполнил её тестовыми данными с помощью библиотеки Faker и написал SQL-запросы для работы с задачами и пользователями.

**Что использовал:**

- Python
- PostgreSQL 16
- psycopg2 — подключение Python к PostgreSQL
- Faker — генерация случайных тестовых данных
- Docker — запуск PostgreSQL в контейнере

## 2. Структура базы данных

В базе `task_management` находятся три таблицы.

### `users` — пользователи

| Столбец | Назначение                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| `id`         | Уникальный ID пользователя                                                       |
| `fullname`   | Полное имя                                                                                    |
| `email`      | Электронная почта, уникальная для каждого пользователя |

### `status` — статусы задач

| Столбец | Назначение                                  |
| -------------- | ----------------------------------------------------- |
| `id`         | Уникальный ID статуса                |
| `name`       | Название статуса, уникальное |

Используются три статуса:

- `new` — новая задача;
- `in progress` — задача в работе;
- `completed` — задача завершена.

### `tasks` — задачи

| Столбец  | Назначение                                                     |
| --------------- | ------------------------------------------------------------------------ |
| `id`          | Уникальный ID задачи                                     |
| `title`       | Название задачи                                            |
| `description` | Описание задачи                                            |
| `status_id`   | Ссылка на статус из таблицы `status`            |
| `user_id`     | Ссылка на пользователя из таблицы `users` |

Связи между таблицами:

- Одна задача связана с одним пользователем.
- Одна задача имеет один статус.
- У одного пользователя может быть несколько задач.
- При удалении пользователя его задачи удаляются автоматически благодаря `ON DELETE CASCADE`.

## 3. Файлы проекта

### `create_tables.py`

Создаёт таблицы `users`, `status` и `tasks`.

В этом файле используются:

- `CREATE TABLE IF NOT EXISTS` — создание таблицы, если её ещё нет;
- `PRIMARY KEY` — первичный ключ;
- `UNIQUE` — запрет повторяющихся значений;
- `REFERENCES` — внешний ключ;
- `ON DELETE CASCADE` — каскадное удаление задач пользователя.

Важно: `IF NOT EXISTS` не изменяет структуру уже существующей таблицы.

### `seed.py`

Заполняет базу случайными тестовыми данными.

В файле находятся три функции:

- `seed_users()` — создаёт пользователей;
- `seed_statuses()` — добавляет статусы;
- `seed_tasks()` — создаёт задачи и назначает их случайным пользователям и статусам.

Для генерации данных используется Faker, а `random.choice()` выбирает случайные ID пользователей и статусов.

Также используются:

- `commit()` — сохранение изменений;
- `rollback()` — отмена незавершённых изменений при ошибке;
- `try / except / finally` — обработка ошибок и закрытие ресурсов;
- `%s` — безопасная передача значений в SQL-запросы через psycopg2.

**Важно:** при запуске `seed.py` создаются 20 пользователей и 30 задач. Повторные запуски добавляют новых пользователей и задачи, а существующие статусы пропускаются. Поэтому не стоит запускать скрипт повторно без необходимости.

### `query.sql`

Содержит 14 SQL-запросов из домашнего задания:

1. Получение задач конкретного пользователя.
2. Поиск задач по статусу с помощью подзапроса.
3. Обновление статуса задачи.
4. Поиск пользователей без задач через `NOT IN`.
5. Добавление новой задачи через `INSERT`.
6. Получение незавершённых задач.
7. Удаление задачи через `DELETE`.
8. Поиск пользователей по электронной почте через `LIKE`.
9. Обновление имени пользователя.
10. Подсчёт задач по статусам через `COUNT` и `GROUP BY`.
11. Поиск задач пользователей по домену электронной почты с помощью `JOIN`.
12. Поиск задач без описания через `IS NULL`.
13. Получение пользователей и задач со статусом `in progress` через `INNER JOIN`.
14. Подсчёт задач каждого пользователя через `LEFT JOIN` и `GROUP BY`.

## 4. Как запустить проект

### Шаг 1. Запустить PostgreSQL

PostgreSQL работает в Docker-контейнере `task-management-db`.

Если контейнер уже создан и остановлен, его можно запустить:

```bash
docker start task-management-db
```

Проверить состояние контейнера:

```bash
docker ps
```

### Шаг 2. Установить зависимости Python

В терминале VS Code:

```bash
python -m pip install psycopg2-binary Faker python-dotenv
```

Если `python` указывает не на нужный интерпретатор, используй команду с путём к своему Python.



### Настройка проекта

Перед запуском скриптов:

1. Создайте файл `.env` на основе шаблона `.env.example`:
   ```bash
   cp .env.example .env
   ```
2. Откройте файл `.env` и укажите свои настройки подключения к PostgreSQL.
3. Убедитесь, что сервер PostgreSQL запущен, а параметры подключения соответствуют настройкам вашей базы данных.

**Важно:** файл `.env` содержит локальные настройки подключения и не должен попадать в Git. Файл `.env.example` используется как шаблон и предназначен для публикации вместе с проектом.

### Шаг 3. Создать таблицы

```bash
python create_tables.py
```

Команда создаёт таблицы, если их ещё нет. Она не очищает существующие данные.

### Шаг 4. Заполнить базу

```bash
python seed.py
```

Запускай этот шаг на пустых таблицах, если хочешь получить исходный набор из 20 пользователей, трёх статусов и 30 задач.

### Шаг 5. Подключиться к базе

```bash
docker exec -it task-management-db psql -U postgres -d task_management
```

Для выхода из PostgreSQL:

```text
\q
```

## 5. Полезные команды PostgreSQL

Посмотреть таблицы:

```text
\dt
```

Посмотреть структуру таблицы:

```text
\d tasks
```

Посчитать количество пользователей:

```sql
SELECT COUNT(*) FROM users;
```

Посчитать количество задач:

```sql
SELECT COUNT(*) FROM tasks;
```

Посмотреть задачи вместе с именами пользователей и статусами:

```sql
SELECT
    tasks.id,
    tasks.title,
    users.fullname,
    status.name AS status
FROM tasks
JOIN users ON tasks.user_id = users.id
JOIN status ON tasks.status_id = status.id
LIMIT 10;
```

Отключить постраничный вывод результатов:

```text
\pset pager off
```
