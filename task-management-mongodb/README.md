# Управление коллекцией котов в MongoDB

## Описание проекта

Проект представляет собой Python-приложение для управления коллекцией
котов в базе данных MongoDB с использованием библиотеки PyMongo.

Приложение позволяет просматривать записи, искать котов по имени,
изменять их возраст, добавлять характеристики и удалять записи.

## Технологии

-   Python 3.14
-   MongoDB 8
-   PyMongo
-   Docker

## Структура документа

Каждый документ содержит следующие поля:

-   `_id` --- уникальный идентификатор, автоматически создаваемый
    MongoDB.
-   `name` --- имя кота.
-   `age` --- возраст кота.
-   `features` --- список характеристик кота.

Пример документа:

``` json
{
    "name": "barsik",
    "age": 3,
    "features": [
        "ходит в тапки",
        "даёт себя гладить",
        "рыжий"
    ]
}
```

## Возможности приложения

1.  **Просмотр всех котов** --- вывод всех документов из коллекции.
2.  **Поиск кота** --- поиск записи по имени.
3.  **Изменение возраста** --- обновление возраста кота по имени.
4.  **Добавление характеристики** --- добавление нового элемента в
    список `features`.
5.  **Удаление кота** --- удаление одной записи по имени.
6.  **Удаление всех котов** --- очистка коллекции после подтверждения
    действия.
7.  **Обработка ошибок** --- обработка ошибок взаимодействия с MongoDB и
    некорректного ввода возраста.

## Установка и запуск

### 1. Запуск MongoDB через Docker

Убедитесь, что Docker Desktop запущен.

Если контейнер ещё не создан, выполните:

``` bash
docker run -d \
  --name task-management-mongodb \
  -p 27017:27017 \
  -v mongodb_data:/data/db \
  mongo:8
```

Если контейнер уже создан и остановлен, повторно создавать его не нужно.
Запустите существующий контейнер:

``` bash
docker start task-management-mongodb
```

### 2. Установка PyMongo

Установите необходимую библиотеку:

``` bash
python -m pip install pymongo
```

### 3. Запуск приложения

В терминале перейдите в папку проекта и выполните:

``` bash
python main.py
```

После запуска приложение проверит подключение к MongoDB и покажет меню
управления котами.

## Начальные данные

Если коллекция пуста, приложение автоматически добавляет двух примеров
котов: Барсика и Мурзика.

Если коллекция уже содержит документы, начальные данные повторно не
добавляются.

После удаления всех котов они будут добавлены снова при следующем
запуске приложения, если коллекция останется пустой.

## Обработка ошибок

Приложение обрабатывает ошибки подключения и операций с MongoDB, а также
проверяет корректность ввода возраста. Возраст должен быть целым
неотрицательным числом.
